# KiCad Libraries

Libraries for KiCad. Reference them with `${APRL_LIBS}/...`, set to this folder
in Preferences -> Configure Paths.

## aprl/

First-party libs drawn by APRL. Every library is named `APRL_*`.

Stock KiCad symbols, footprints and 3D models are not vendored; they come from
KiCad's own global libraries. Board lib tables list only this folder; rewrite
them with `just sync-libs`.

## vendor/

Third-party libs generated by others.

## models/

3D models KiCad does not ship, flat and keyed by filename. Referenced as
`${APRL_LIBS}/models/<file>`. Stock models stay `${KICAD10_3DMODEL_DIR}/...`.

## Drawing sheets and rules

`APRL_Schematic_Sheet.kicad_wks`, `APRL_Layout_Sheet.kicad_wks` and
`jlcpcb-4layer.kicad_dru`. Title-block fields are project text variables.

## Adding a part

Symbol goes in the `APRL_*.kicad_sym` matching its function, footprint in the
matching `APRL_*.pretty`, 3D model in `models/`. Third-party parts go in
`vendor/`.
